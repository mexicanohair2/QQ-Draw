# QQ Draw — QQCross

QQ Draw — игра в рисование и угадывание слов с цифровым холстом, локальными ботами и общими комнатами QQCross.

## Запуск

Проект публикуется как статическое приложение GitHub Pages.

- **Угадывать рисунок бота:** бот рисует простой, намеренно несовершенный эскиз; игрок вводит догадку.
- **Рисовать для ботов:** игрок выбирает слово и рисует; два простых бота делают неторопливые случайные догадки.
- **Комната QQCross:** создать комнату либо подключиться по шестизначному коду через существующий аккаунт QQCross.

Для входа используются те же почта/пароль и профиль QQCross. Отдельной регистрации, друзей или профиля игра не создаёт. В браузере сессии разных GitHub Pages адресов изолированы, поэтому вход в игру и основной QQCross выполняется отдельно, но аккаунт остаётся общим.

## Серверный контракт

Общий Supabase-проект:
- `auth.users` и `profiles` — единый аккаунт, ник и аватар;
- `qq_party_rooms` и `qq_party_players` — общая серверная комната;
- `qq_party_secrets` и `private.qq_party_draw_choices` — секретное слово и варианты, скрытые от угадывающих;
- `qq_party_draw_events` — отдельные события холста, не изображения.

RPC:
- `qq_party_create_room`, `qq_party_join_room`, `qq_party_get_room`, `qq_party_leave_room`;
- `qq_party_start_crocodile`, `qq_party_refresh_croc_choices`, `qq_party_confirm_croc_word`;
- `qq_party_croc_guess`, `qq_party_next_croc_round`;
- `qq_party_add_stroke`, `qq_party_clear_canvas`, `qq_party_undo_canvas`;
- `qq_party_get_draw_events` — курсорное восстановление по порядковому номеру.

При старте сервер случайно назначает художника и выдаёт ему приватные варианты слова. После подтверждения только художник получает ответ. Угадывающие видят холст и общую историю, но не секрет. Угадавший становится художником следующего раунда.

Каждый штрих передаётся как begin/move/end с идентификатором раунда, игрока, координатами 0..1, цветом, толщиной и последовательным номером. Сервер проверяет членство в комнате, право художника, раунд, диапазоны значений, порядок и дубликаты. История штрихов восстанавливается страницами по 1000 событий; Realtime сообщает о новых изменениях. Изображение целиком после каждого движения не отправляется.

Сетевые комнаты доступны только подтверждённым неанонимным аккаунтам QQCross с профилем. Участник и аватар берутся из серверной сессии и профиля; ботов нельзя добавить через RPC. Боты существуют только в локальном одиночном режиме.

## Проверка

`npm test` проверяет уникальность слов, работу локального бота, последовательности и восстановление холста. GitHub Actions запускает тесты до публикации Pages.

Реальную работу двух и более телефонов нужно отдельно проверить с независимыми аккаунтами. Автоматические unit-тесты не подтверждают устойчивость Realtime при потере соединения.

## Публичный запуск

Текущая публичная публикация: **https://qqcross-qq-draw.vercel.app/**

Приложение развёрнуто из этого GitHub-репозитория как статический сайт в Vercel. Автоматическое обновление от каждого git push пока не подключено, поэтому при изменении файлов нужно повторить deployment.

## GitHub Pages — альтернативный вариант

GitHub Pages workflow уже настроен, но сам Pages Site не создан, потому что GitHub блокирует его создание из подключённой интеграции.

1. Открой [Settings → Pages](https://github.com/mexicanohair2/QQ-Draw/settings/pages).
2. В разделе **Build and deployment** выбери **Source: GitHub Actions**.
3. Открой вкладку [Actions](https://github.com/mexicanohair2/QQ-Draw/actions) и повтори workflow **Test and deploy**.

Workflow запускает `node --check app.js` и `node --test`; публикация выполняется только после успешного тестового задания.

## Приглашения друзей QQCross

В комнате ожидания отображается существующий список друзей QQCross. Хост или участник может отправить приглашение; сервер проверяет дружбу и свободные места. Получателю приходит приглашение в общем блоке **«Приглашения в партии»** главного QQCross. После принятия доступна ссылка на эту игру с кодом комнаты.

Прямая ссылка на принятие открывает игру с параметром `?room=КОД`. Если в этом браузере ещё нет сессии Supabase для данного домена, нужно войти тем же аккаунтом QQCross; после входа игра автоматически подключит пользователя к комнате. Отдельный аккаунт или список друзей не создаются.
